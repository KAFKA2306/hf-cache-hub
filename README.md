# hf-cache-hub

[![CI](https://github.com/KAFKA2306/hf-cache-hub/actions/workflows/pinned-cache.yml/badge.svg)](https://github.com/KAFKA2306/hf-cache-hub/actions/workflows/pinned-cache.yml)

Hugging Face modelをrevision固定で共有cacheへ配置し、複数projectから同一snapshotを参照するためのbootstrap utilityです。生成artifactはGitへlarge binaryを置かず、Hugging Face Storage Buckets上のobjectをSHA-256、size、生成元Git revisionで検証して共有します。

## Setup

```bash
git clone https://github.com/KAFKA2306/hf-cache-hub.git ~/src/hf-cache-hub
export HF_CACHE_HUB_ROOT="$HOME/src/hf-cache-hub"
export HF_HOME="$HOME/hf-cache"
python -m pip install "PyYAML>=6.0,<7" "huggingface-hub>=1.0,<2" "filelock>=3.0"
```

## Generated artifactを共有する

project repositoryにはsource code、small config、thin manifestだけを置きます。PLY、checkpoint、video、dataset等のlarge generated bytesやcredentialはGitへ保存しません。

例: `artifacts.yaml`

```yaml
schema_version: 1
artifacts:
  - id: example/splat
    kind: gaussian-splat
    format: ply
    storage:
      type: huggingface-bucket
      bucket: KAFKA2306/artifacts
      path: gaussian/example/splat.ply
    size_bytes: 123456
    sha256: 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
    provenance:
      repository: KAFKA2306/AutoPhotogrammetry
      revision: 0123456789abcdef0123456789abcdef01234567
      source_path: output/example/export/splat.ply
```

manifestを検証:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_manager.py" \
  --manifest ./artifacts.yaml \
  validate
```

producerからpublish:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_manager.py" \
  --manifest ./artifacts.yaml \
  publish ./output/splat.ply \
  --id example/splat
```

remoteへ書かず確認する場合:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_manager.py" \
  --manifest ./artifacts.yaml \
  publish ./output/splat.ply \
  --id example/splat \
  --dry-run
```

consumer側でshared cache状態を確認:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_cache.py" \
  plan \
  --manifest ./artifacts.yaml
```

取得:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_cache.py" \
  resolve \
  --manifest ./artifacts.yaml \
  --id example/splat
```

verified objectは既定で次へ保存されます。

```text
$HF_HOME/artifacts/sha256/<sha256>/<filename>
```

既存pathへmaterializeする場合:

```bash
python "$HF_CACHE_HUB_ROOT/scripts/artifact_cache.py" \
  resolve \
  --manifest ./artifacts.yaml \
  --id example/splat \
  --materialize ./Library/MyProject/GaussianSources/example.ply
```

既定はshared cache objectへのsymlinkです。symlinkを作れない環境で明示的にcopyを許可する場合だけ `--copy-fallback` を指定します。

publishはlocal size/SHA-256を検証してuploadし、remote objectをread-backして再検証します。完全一致した場合だけ `PUBLISHED` です。consumerはmanifestと一致するcache objectを得た場合だけ `READY` と扱います。Storage Bucketのpathはmutableなので、pathだけをartifact identityには使いません。

詳細なacceptance境界は [docs/artifact-storage-acceptance.md](docs/artifact-storage-acceptance.md)、複数projectへの導入手順は [docs/services/team-cache-bootstrap.md](docs/services/team-cache-bootstrap.md) を参照してください。

## Model cache

```bash
export HF_HOME="$HOME/hf-cache"
export HF_HUB_CACHE="$HF_HOME/hub"
```

`models.yaml` では `org`、`repo`、full 40-character `revision`、`purpose`、`access`、`license_url`、`model_card_url` を宣言します。tokenやsecretはmanifestへ書きません。

```yaml
models:
  - org: Tongyi-MAI
    repo: Z-Image-Turbo
    revision: f332072aa78be7aecdf3ee76d5c247082da564a6
    purpose: image-generation
    access: PUBLIC
    license_url: https://www.apache.org/licenses/LICENSE-2.0
    model_card_url: https://huggingface.co/Tongyi-MAI/Z-Image-Turbo
```

Download前のcache状態を確認:

```bash
task hf:plan
```

指定revisionをdownloadし、そのrevisionのsnapshotだけをlinkして `cache-manifest.json` を生成:

```bash
task hf:sync
```

生成link:

```text
models/REPO -> $HF_HUB_CACHE/models--ORG--REPO/snapshots/<pinned-commit>
```

`hf:sync` はsnapshotのmtimeから「最新」を推測しません。download APIが返したsnapshot名が指定revisionと一致しなければ失敗します。

cache管理:

```bash
task hf:ls
task hf:prune
```

gated/private repositoryは利用者自身のHugging Face credentialを使用します。credentialが取得できなければsyncしません。license URL/model card URLは確認先として保持するだけで、商用利用可否を自動判定しません。

## Repositoryで保持するもの

保持するもの:

- source code
- small config
- thin manifest
- `size_bytes` / SHA-256
- exact Git revisionとrun/source provenance
- 必要ならignored materialization path

保持しないもの:

- large generated bytes
- Hugging Face token、password、API key等のcredential
- projectごとに複製したStorage Bucket upload/download実装
- mutableなBucket pathだけを根拠にしたartifact identity
